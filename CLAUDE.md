# quanta-funnel

Воронка продаж партнёрской программы Quanta Tech.

## Структура

- **index.html** — основной лендинг (описание эко, тарифы $150/$405/$1440)
- **app.html** — Telegram Mini App (5 вкладок):
  - 💰 Доход: калькулятор партнёрки (50% с каждой продажи)
  - 🧭 Тариф: интерактивный квиз (3 вопроса → рекомендация)
  - 🎯 Путь: чеклист из 10 шагов до первой продажи (localStorage)
  - 🧠 Внутри: описание инструментов BrandMind и PromoStudio
  - ❓ FAQ: частые вопросы про платежи, модели участия
- **thanks.html** — спасибка после формы с ссылками на 3 PDF
- **pdf-*.html / pdf-*.pdf** — разборы (Blogger-модель, Protocol-модель, combo)

## Стиль

Тёмная тема (bg #07070C, text #F4F4F7). Цвета: фиолет #7C5BFF, бирюза #00E5C7. Шрифт: Inter / системный sans-serif. Адаптивный дизайн (основной размер до 780px).

## Как запустить

Просто открыть HTML в браузере. Статика, без сборки. Для Telegram Mini App — копировать URL app.html в настройки бота.

## Что менять

- **Таблица тарифов** (app.html, строка 129–133): цены, названия
- **Квиз** (app.html, строка 319–343): вопросы, ответы, рекомендации
- **Чеклист пути** (app.html, строка 244–255): этапы до первой продажи
- **Ссылка на регистрацию** (app.html, строка 241): REG_URL с кодом партнёра
- **Лендинг** (index.html): весь контент inline в HTML

Все изменения — прямо в HTML. Никаких файлов конфига. localStorage для состояния чеклиста.
